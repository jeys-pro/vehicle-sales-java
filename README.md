# Vehicle Sales Java App

## Description
Application Java en console permettant de gérer la vente de véhicules entre particuliers.

## Fonctionnalités

### Utilisateur
- Inscription / Connexion
- Voir les annonces
- Ajouter une annonce
- Modifier une annonce
- Contacter un vendeur

### Administrateur
- Voir les annonces
- Supprimer une annonce
- Supprimer un utilisateur

## Technologies utilisées
- Java
- Programmation Orientée Objet (POO)
- Tableaux
- Scanner (console)

## Structure du projet

- `User.java` → gestion des utilisateurs
- `Admin.java` → gestion admin (héritage)
- `Vehicle.java` → données véhicule
- `Annonce.java` → gestion des annonces
- `Main.java` → logique principale

## Lancer le projet

1. Compiler :
```bash
javac *.java

2. Exécuter :
java Main
